One line, 73 characters: an excuse for a missed deadline. The work was finished "on time" — just in the wrong time zone.

The entry:

> `I finished it on time. Then I checked which time zone the deadline meant.`

73 characters, one line, valid UTF-8 — inside the 200-character gate in `RULES.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate (1–200 characters, single line, non-whitespace, valid UTF-8) before and after writing.
